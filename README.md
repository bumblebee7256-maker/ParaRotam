# ParaRotam – güncellenmiş Android kaynak projesi

Bu proje gönderilen ParaRotam-main.zip içindeki güncel Android uygulamasının devamıdır.

Mevcut özellikler: ana sayfa, gelir, gider, borç, kart, birikim, zam yönetimi, analiz, Android bildirimleri, yedekleme.

Ek düzeltmeler: seçilen tarihten başlayan zamlar, bekleyen geçmiş giderlerin görünümü, kart ekstresi aylık kayıtları, bildirim eşitlemesi ve GitHub Actions APK derleme yapılandırması.

**Sınırlamalar:** Ödenmeyen geçmiş giderler bilgi amaçlı listelenir; otomatik yeni borç kaydı açılmaz. Kredi kartı ekstreleri için tüm muhasebe mutabakatı henüz kapsamlı test edilmemiştir. Android SDK bulunmadığından gerçek APK derlenmemiş ve cihaz testleri yapılmamıştır.

Kurulum: ZIP'i açıp içindeki tüm dosyaları GitHub deposunun kök dizinine yükleyin. Actions > ParaRotam Android APK > Run workflow.

ÖNEMLİ: Mevcut uygulama verilerinizi önce Ayarlar > Yedek indir ile saklayın. Yeni uygulama imzası veya paket kimliği değişirse eski veriler otomatik taşınmayabilir.
